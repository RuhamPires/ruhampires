# SnapClean — Material Master Data Quality

**Professional project · Multilingual matching · Human-in-the-loop validation**

SnapClean addresses duplicate, incomplete and inconsistent SAP material records. The workflow combines cross-language matching, AI-assisted review and human validation.

## Documented scope

The existing public professional summary describes a catalog of more than 228,000 materials, with 82,296 duplicate families mapped from approximately 1.54 million candidate pairs.

These quantities describe the matching and review scope. A mapped candidate or family is not equivalent to a confirmed, merged or deleted duplicate. This repository does not publish the underlying SAP records.

## Technology context

Python, Azure AI, embeddings, data-quality processing and SAP integration.

## Engineering focus

- Generate candidate matches across inconsistent and multilingual descriptions.
- Distinguish matching suggestions from confirmed data corrections.
- Combine an AI second opinion with human review.
- Preserve enough context for reviewers to understand why records were grouped.
