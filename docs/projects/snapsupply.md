# SnapSupply — AI Part Identification

**Professional project · TK Elevator · Computer vision and hybrid search**

SnapSupply supports the identification of elevator spare parts from images. The application connects visual input with an industrial parts catalog so field users can find candidate components.

## Contribution

End-to-end design and development, from the initial concept to deployment. The professional scope previously documented in this public profile includes:

| Dimension | Reported project scope |
| --- | --- |
| Catalog | 228,844 SAP SKUs |
| Search index | Approximately 860,000 documents |
| Rollout | 12 sites across 3 continents |
| Languages | Portuguese, English, German, Spanish and Chinese |
| Response time | Previously reported as under 3 seconds |

These figures describe the professional project as documented in the profile. This public repository does not contain the production dataset, telemetry or a reproducible latency benchmark.

## Technology context

Azure OpenAI with visual input, Azure AI Search with vector and hybrid retrieval, Python, FastAPI, React, Cosmos DB, Docker and Azure DevOps CI/CD.

## Engineering focus

- Relate a field image to a large, structured industrial catalog.
- Consider image quality, visually similar components and multilingual descriptions.
- Connect retrieval and model output to a usable application workflow.
- Support deployment and integration across multiple operating locations.

The [public technical presentation](https://github.com/RuhamPires/presentation) is a separate design proposal for fine-grained visual similarity. Its proposed model choices and target metrics should not be confused with measured production results.
