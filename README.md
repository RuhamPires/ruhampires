## About Me

I build **enterprise AI systems** that solve real-world operational problems at scale. I have been coding since I was a kid — shipped my first professional web project in 2016 — and spent years inside real industrial operations (solar energy projects, manufacturing maintenance and automation) before specializing in Data Science & AI (postgraduate degree, 2025).

That mix is my edge: I build AI for field operations because I have been on the other side of it.

Currently at **TK Elevator**, where I designed and built SnapSupply end to end — from zero to production across 12 sites, 3 continents and 5 languages.

## Featured Projects

### SnapSupply - AI Part Identifier
> *Enterprise computer vision platform identifying elevator spare parts in under 3 seconds*

| Metric | Value |
|--------|-------|
| Catalog Size | 228,844 SAP SKUs |
| Search Index | 860k documents |
| Response Time | < 3 seconds |
| Scale | 12 sites · 3 continents |
| Languages | 5 (PT · EN · DE · ES · ZH) |

**Stack:** Azure OpenAI (GPT-4V) | Azure AI Search (vector + hybrid) | Python | FastAPI | React | Cosmos DB | Docker | Azure DevOps CI/CD

---

### SnapClean - Material Master Data Sanitation
> *Intelligent data cleansing for SAP material master records*

Automated detection and resolution of duplicate, incomplete and inconsistent records across 228K+ SAP materials — 82,296 duplicate families mapped from 1.54M candidate pairs by a cross-language matching engine, with AI second opinion and human-in-the-loop validation.

**Stack:** Python | Azure AI | Embeddings | Data Quality | SAP Integration

---

### SnapDispatch - Intelligent Technician Dispatch
> *Control tower with real-time dispatch for field operations*

Route optimization, multi-criteria scoring (proximity, specialty, workload, rating) and a mobile field app (PWA) with digital checklist, photo capture and signature.

**Stack:** Python | Route Optimization (OSRM) | React (PWA) | Dashboards
